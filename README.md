Sistema de console em Java para gerenciamento de aluguel de quadras esportivas, permitindo agendamentos e visualização de reservas.

Funcionalidades Principais
Listagem de quadras disponíveis com preços

Sistema de agendamento por horários

Cálculo automático de valores baseado no tempo

Visualização de agendamentos existentes

Interface simples via terminal.
